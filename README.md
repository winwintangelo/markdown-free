## Features

- Drag & drop file upload or paste Markdown directly
- Live preview before exporting
, `$…$`, `\(…\)`, `\[…\]`) rendered with KaTeX; Mermaid diagrams rendered as images in every format
- Paste cleanup for AI-chat copies (ChatGPT, DeepSeek, Kimi, Doubao, Gemini): strips copy buttons, role labels, `<think>` blocks and citation glyphs
- HTML, TXT, image, EPUB and Excel exports run entirely in the browser; long-document images become one tall image or a ZIP of parts
- GitHub Flavored Markdown (tables, task lists, code blocks)
- No signup, no watermarks, no tracking cookies
- 10 languages: EN, ES, IT, ZH-Hant, ZH-Hans, JA, KO, ID, VI, HI
